# MKJ Children School

Production-oriented React + Vite website for MKJ Children School.

## Current build status

- Section 1: Responsive animated navbar
- Section 2: Animated hero section
- Section 3: About / mission with animated stats
- Section 4: Academics / programs grid
- Section 5: Campus life / gallery
- Section 6: Testimonials
- Section 7: Admissions / CTA
- Section 8: Footer — pending

## Stack

- React
- Vite
- Motion (`motion/react`)
- Plain CSS

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The UI includes responsive breakpoints, keyboard focus states, accessible navigation labels, and `prefers-reduced-motion` handling.
